**More keyboard shortcuts.** `Tab` and `Shift+Tab` switch inbox tabs while nothing on the page has
the focus. `Esc` goes back to the list from an open conversation, after closing any open menu first.
`Shift+J` and `Shift+K` select the highlighted conversation and the next one down or up, so a run
can be selected key by key. `g` then `b` goes to Snoozed. The help sheet lists them all. No schema
change.
