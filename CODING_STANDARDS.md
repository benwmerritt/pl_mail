# Coding standards

Rules the fork adds on top of upstream's CODESTYLE.md and DESIGN.md, each one a point reviews of fork pull requests raised more than once. The review pass checks a diff against them, alongside upstream's documents and the issue it implements.

- **Tooltip text has one owner.** Code that reads or adds to a control's tooltip handles both `title` and `data-tooltip`. Once `ui--tooltip` (`assets/controllers/ui/tooltip_controller.js`) has moved the text into `data-tooltip`, update `data-tooltip` and leave `title` unset. [#15](https://github.com/benwmerritt/pl_mail/pull/15#discussion_r4711235689), fixed in `c852dc19`; [#20](https://github.com/benwmerritt/pl_mail/pull/20#discussion_r4712172195), fixed in `dd91b2b4`.
- **A shortcut hint names what the key does there.** Resolve a hint or a command-box entry against the control `ui--shortcuts` (`assets/controllers/ui/shortcuts_controller.js`) actually targets. A control gets a hint only if its key can reach it, and the command box offers an action only where it exists, such as Reply all. [#15](https://github.com/benwmerritt/pl_mail/pull/15), fixed in `c852dc19`; [#20](https://github.com/benwmerritt/pl_mail/pull/20), fixed in `b8c915fe`.
- **The list cursor survives selection and auto-advance.** After auto-advance, sync the cursor to the row marked `data-selected`. With a conversation open, Shift+J/K extends from the current cursor and uses the open row only to place it the first time. Owners: `shortcuts_controller.js` and `assets/controllers/mail/mail_pane_controller.js`. [#8](https://github.com/benwmerritt/pl_mail/pull/8), fixed in `346fc250`; [#16](https://github.com/benwmerritt/pl_mail/pull/16#discussion_r4711517562), fixed in `ab2ab646`.
- **One Escape does one thing.** A menu or panel that handles Escape consumes the press before the global Back shortcut sees it, and returns focus to the visible control that opened it. Back still runs past panels that close with the conversation. Owners: `assets/controllers/mail/label_menu_controller.js` and `shortcuts_controller.js`. [#14](https://github.com/benwmerritt/pl_mail/pull/14), fixed in `18a1371f`; [#16](https://github.com/benwmerritt/pl_mail/pull/16#discussion_r4711517576), fixed in `ab2ab646` and `86eb557d`.
- **Keys belong to the input method while it composes.** A mail control that intercepts navigation or submit keys, Ctrl/⌘+Enter included, first checks `event.isComposing`, as Compose does. [#10](https://github.com/benwmerritt/pl_mail/pull/10), fixed in `f5a2533c`; [#14](https://github.com/benwmerritt/pl_mail/pull/14#discussion_r4710999693), fixed in `18a1371f`.
- **A late response acts only on the screen that asked.** Before a response replaces the reading pane or browser history, check the user has not moved on. A late response may still show its Undo toast, but closes only the picker that submitted it. Owners: `mail_pane_controller.js` and `assets/controllers/mail/agent_forward_controller.js`. [#8](https://github.com/benwmerritt/pl_mail/pull/8#discussion_r4710612396), fixed in `4488b2c0` and `ee7c64fd`; [#10](https://github.com/benwmerritt/pl_mail/pull/10), fixed in `f5a2533c`.
